## 0. 一句话世界观

> 世界曾是一整片海。海的最深处有一颗心——有人凿穿了它。
> 潮水从此三分：坠入地底的被火煮成熔岩，落在地上的化作江河湖海，蒸发上天的那一部分散成了风。
> 只有末地——潮从未到达的彼岸——还保持着涨潮之前的样子。
> 四个界层，是一场大灾变的四块碎片。玩家推开一扇又一扇门，走在碎片的接缝上。

## 1. 定位：从复刻到自有身份

### 1.1 现状与目标

- 现状（Build 23 核对）：四界叙事首轮补全**已全部落地**——天域·天海纪元（Build 14）、下界·烬火纪（Build 15）、主世界·雨土纪（Build 16）、末地·无潮彼岸（Build 17）、终局·潮归其位（Build 18）、天域后传·鲸骨冢（Build 19）；Build 20–23 为非叙事批次（修复 / 皮肤 / LAN 组件），未动叙事层。
- 目标（原则不变）：不是重写玩法，而是**给既有内容一个来历**——玩法机制、方块 id、生物行为零改动，叙事层（结构 / 碑文 / lore / 命名）补全，使项目获得"原版 MC 拿不走"的叙事身份。后续新增叙事内容仍按 §9 立项模板从 §10 先例取式。
- 检验标准（复用天域篇 §6 的口径）：玩家不读任何文案也能正常游玩；读了文案，世界里的每一样东西都开始"有理由"。

## 2. 世界总轴：一潮三分

### 2.1 原初之潮

世界诞生时只有一整片海，包裹着所有的界层——**原初之潮**。潮的最深处沉着一颗心脏，**天穹之心**，托举潮水、维系四界的潮枢。海中有生民：天上的云民、地底的火民、大陆上的雨民（见 §4 众生相）。各界依潮而活，互通有无。

### 2.2 裂潮之日（全项目因果主链）

云民采掘星髓穷尽浅层后凿穿了天穹之心（天域篇年表 §2.2「掘心之祸→裂潮之日」）。心壳碎裂，潮水失去锚，**一潮三分**：

| 去向 | 落点 | 既有事实的缝合 |
|---|---|---|
| **坠** | 穿过天域岛列，坠入地底 | 下界熔岩海 = 被 地火煮沸的坠潮（`nether.js` lava_sea 群系） |
| **落** | 化作暴雨落在大陆 | 主世界江海与所有水体 = 天海的雨养之潮（主世界海平面 Y=64） |
| **蒸** | 蒸发成风，回到天顶 | 天域无水体 + 永昼的"风化之殇"（`aether.js` 无水体 + 天海纪元终局） |
| **不及** | 潮从未到达的远方 | 末地 = 无潮彼岸（无水、苍白、虚空） |

- 这条链是**文档级缝合**：只在碑文 / lore / 命名中呼应，不实装任何跨维度联动机制（与天域篇 §5.6 同款边界）。
- 推论（供新内容取用）：荧石 = 坠潮凝光（见 §3.2）；灵魂沙 = 坠潮裹挟的溺亡骨泥；两者都是"潮的遗骸"，因此天然带潮之记忆——这是"下界物产为什么能造界门"的自洽解释。

### 2.3 跨维度纪元年表

| 纪元 | 四界状态 | 可考遗迹 |
|---|---|---|
| **潮平纪元** | 一整片海。云民航于天涛，火民炉于地底潮火，雨民的先祖尚在海上 | —（无遗迹：太古老） |
| **星髓时代** | 云民鼎盛，凿通界壁，与火民换火、与地上人换粮 | 天域瞭望塔 / 天海之门遗迹（天域篇已交付） |
| **裂潮之日** | 天穹之心碎裂，一潮三分。云民或坠或散；火民的地底世界被坠潮灌入；大陆迎来第一场雨 | 下界熔岩海 / 主世界江海 / 天域永昼 |
| **烬火纪元**（下界现在） | 坠潮被地火煮沸成熔岩海，火民在潮火中坚守炉火，或已灭绝——只有炉还在烧 | 下界要塞（§3.2 重释） |
| **雨土纪元**（主世界现在） | 雨民的世代：大陆得雨而丰饶，村庄星布。旧潮的遗物沉在海底，被泥沙掩埋 | 村庄 / 要塞 / 海底潮冢（§6.2 提案） |
| **长明之后**（天域现在） | 天域篇五幕旅程 | 天域全部既有内容 |
| **无潮彼岸**（末地现在） | 拾遗者在潮外的荒原上行走、收集、守望。他们的王盘踞主岛，无人知晓王在等什么 | 末地城 / 折跃门 / 龙（§3.4 重释） |

> 四界没有统一的时间流速锚点（不实装），年表只定**先后与因果**，不定绝对年代。

## 3. 四界篇章

### 3.1 天域·天海纪元（✅ 已定稿已交付）

- 全文见 `docs/aether-storyline.md`：退去的天海、永昼的来历、云民的掘心之祸、守誓巨像与复潮终局。
- 在总纲中的定位：**主轴的起点与样板**——"一潮三分"的因在此发生；天域篇验证过的手段（石碑家族、残页 lore、结构即证物、Boss 即叙事）是其余三界的施工模板。

### 3.2 下界·烬火纪（✅ 已实装：Alpha Build 15——烬纹石碑 / 烬火纪碑文 4 章 / 潮火之炉 / 哭嚎者·哀潮之泪）

- **火民**：潮平纪元居于地底的生民，以"潮火"为生——坠潮灌入地底后，他们学会了用界壁裂隙中的地火煮沸潮水，从中提炼光与力。
- **荧石 = 长明灯石（坠潮凝光）**：坠潮的水汽在地火中凝成的发光石。云民当年以荧石为拱凿通界壁，正是因为荧石本是天海坠物、带着潮的归乡记忆（缝合：天域篇年表"以长明灯石为拱" + 荧石产地下界）。
- **灵魂沙 = 溺亡骨泥**：坠潮裹挟的天海亡魂沉入下界泥沙。灵魂沙平原 = 最大沉积带（缝合 `nether.js` soul_sand 群系）；灵魂沙峡谷 = 坠潮冲刷出的旧河道。
- **下界要塞 = 潮火之炉的堡垒**：火民守炉的兵营。烈焰人 = 炉卫（炉火点燃的看守）；凋灵骷髅 = 被炉烟熏黑百年的旧卫遗骸。它们仍在巡逻，因为炉火从未熄灭——哪怕火民可能早已不在（缝合 `fortress` 结构 + blaze / wither_skeleton 现有生成）。
- **凋灵（重释）**：三颗不肯安息的头颅被强行缝成的怨憎聚合体——有人在火民废墟上行了禁忌的拼合。凋零 II = "怨潮蚀骨"（缝合 WitherAI 与凋零 II 现状，只补来历）；下界之星 = 凝固的怨潮之心。
- **基调**：一座还在燃烧的、无人看管的炉子。与天域的"守塔人绝笔"对照：天域是废墟里的等待，下界是废墟里的空转。

### 3.3 主世界·雨土纪（✅ 已实装：Alpha Build 16——碑文 3 章 / 潮冢 / 村庄·要塞碑位 / 雨潮残页）

- **雨民**：天海落雨之后在大陆定居的生民。他们不知道海的来历，只记得祖训："最早的年头，雨是咸的。"（村庄 = 雨民集居地，缝合 `village` + 沙漠变体）
- **铁傀儡 = 仿星铸卫**：雨民传说中的"天上坠落的铁巨人"启发了他们的守家傀儡——形似而神非。星铸卫（天域守卫）是云民以星髓铸成，铁傀儡是雨民用铁的拙劣仿制（缝合 iron_golem 现状 + 村庄补员机制不变）。
- **要塞 = 无潮者的门厅**：潮平纪元末，某些"不属任何一界的生民"（拾遗者，见 §3.4）在大陆深处修建的界壁门厅，通往无潮彼岸。末影之眼 = 凝视彼岸的眼——掷眼定位，是眼在"认路回家"（缝合 stronghold + 掷眼机制）。
- **蘑菇岛 = 潮渍之地**：落雨最浓处的巨菌遗迹（弱暗示，不改群系参数）。
- **基调**：丰饶而失忆的大陆。雨民的日子过得最好，也离真相最远。

### 3.4 末地·无潮彼岸（✅ 已实装：Alpha Build 17——界纹石碑 / 彼岸碑文 2 章 / 拾遗者石环 / 主岛守望界碑 / 拾遗者体系 lore）

- **无潮之地**：裂潮之日，潮水涌向三个方向，唯独没有到达这里。末地保留着涨潮之前的世界底色——苍白、寂静、无水（缝合 `end.js` 群系表与虚空）。
- **拾遗者（末影人重释）**：裂潮之日四散的收集者。潮碎成了四块，他们行走于界壁之间，把散落的遗物一件件拾走、搬运、存放——**搬运方块的原版行为 = 拾遗的职业习惯**。凝视会被视为"来抢遗物的"，故而敌意（缝合 enderman AI 不变）。
- **末影龙 = 彼岸的守望**：拾遗者的王，盘踞无潮之环（末地主岛）。它在等什么，碑文不写满——留白（缝合 dragon + 击败链现状）。
- **末地城 = 拾遗者的仓库**：紫颂果 = 他们从别界带回的种子；鞘翅 = 拾遗者滑翔于界壁之间的膜翼（缝合 end_city + 鞘翅战利品）；折跃门 = 他们的界壁捷径（缝合 gateway）。
- **基调**：退潮之后的滩涂尽头。捡了满世界的遗物，却没人知道该怎么用。

## 8. 边界与不做（Out of scope）

- **玩法机制零改动**：本总纲只产出叙事层；任何提案若需要动战斗 / 物理 / 生成器核心参数，必须单独立项评审，不夹带。
- **方块 id / 物品 id 不改不插**：append-only 注册纪律不变（存档数值 id 兼容）。
- **物质层不赋来历**：圆石没有故事，牛没有身世——克制是身份感的前提。
- **不做对话 / NPC 任务系统**；不做 cutscene；不实装跨维度联动机制（水文缝合只存在于文案）。
- **不改群系集合与边界参数**（biomeNames 表稳定，dimension-determinism 必须持续全绿）。
- **重释不与原版机制冲突**：只解释"为什么"，不改"是什么"（例：末影人搬运方块的行为保留，只给它一个职业）。
- **每维度碑文章节数量克制**（天域 9 章是上限参照）：碑文是留白的艺术，写满就廉价了。

### 10.6 全程纪律（三篇通用）

1. 每批交付：`node --check` 改动文件 + 新增单测接入 `server/run-all-tests.sh` + push + CI 绿（`gh run watch --exit-status`）。
2. i18n：新身份层术语先登记 §7 术语表再入码；碑文行数克制（每章 ≤6 行），控制 ×10 翻译成本；i18n-parity 全绿是 CI 门槛。
3. 叙事素材与代码同提交（碑文文案不后补）；篇章完成后按 §9 滚动更新本文档归属表 / 提案池 / 术语表。
4. 旧 seed 的结构分布随密度参数变化而移动：发版说明必须明示（天域 Build 14 先例）。
5. 每篇最后一个批次内 bump `src/version.js` BUILD（发布说明汇总全篇），红线：不变量清单未逐项全绿不进发布流程。
