## 0. 一句话设定

> 天域曾是一片倒悬于世界之上的海。云民在云涛上航行，星髓托着千岛不坠。他们凿开了海底最深处的那颗心脏——潮水退去的那一天，太阳停在了正午，再也没有落下去。
> 你推开荧石门时，正午已经持续了不知多少万年。

1. **为什么永昼？** 目前是纯视觉设定，无解释。

## 2. 故事线：天海纪元

### 2.1 总纲

天域的世界观核心是"**退去的海**"——玩家所见的一切都是一场大灾变的遗迹：

- **浮岛**不是悬空的奇观，而是**干涸海床露出的礁脊**。天海退潮之后，礁石留在了原来的高度。
- **沉船**悬空 12-16 格，是因为海退去时它们正浮在浪上——搁浅在了"半空"这个曾经的水平面上。船底倒挂的水晶柱，是被最后蒸发的潮光侵蚀石化的痕迹。
- **瞭望塔**沿旧航道而建，塔顶荧石是夜航灯——它们见过天海的夜晚，而现在的玩家永远见不到。
- **水晶秘境**是海床最深处的礁脉：星髓（晶柱外壳的石英、地砖里的海晶灯）在那里最浓。云民当年就是在这里挖穿了海底。
- **永昼**是裂潮之日留下的伤疤：天穹之心碎裂后，最重的一块心壳卡在了天空最高处，仍在燃烧最后的漂浮之力，把整片天穹钉死在最后一日的正午。极昼下绕行不落的"太阳"，其实是心壳残光在挣扎。
- **没有水**，是因为天海已经死了：大半坠落穿云，被下界的火煮成了熔岩海；一部分化作雨落在主世界，成了那里的江河湖海。**下界的岩浆海与主世界的海平面，都是天海的遗骸**——三个维度被这一场灾变缝在一起。
- **风灵**是溺亡于天海的水手残魂。潮退了，它们的记忆还在风里"游泳"，一遍遍游向海已经不在的地方。它们没有恶意，只是还在找海（被动、不索敌，正合现有 AI）。
- **天域守卫**是云民以星髓铸成的卫兵，仍在新神殿与晶脉间巡逻，执行裂潮之日收到的最后一道命令：*"守住殿宇与星髓，直到潮水归来。"* 它们攻击玩家，是因为在它们的判据里，任何一个手持镐走近星髓的生物，都和当年凿穿心壳的盗掘者没有区别。

### 2.2 年表

| 纪元 | 事件 | 遗迹对应 |
|---|---|---|
| **涨潮纪元** | 天海充盈，云涛为浪。云民以风帆船航行于群岛之间。 | 天域沉船（搁浅的帆船） |
| **星髓时代** | 礁脉深处发现星髓——凝固的潮之力。千岛因之不坠，长明灯因之不灭。云民鼎盛，沿航路广建瞭望塔。 | 浮空瞭望塔 / 水晶秘境晶柱 |
| **穿界之门** | 云民以长明灯石（荧石）为拱，凿通界壁：向上是"潮升之地"，向下通火民之域。与地面人换粮，与下界火民换火。 | 荧石传送门（玩家来时的路，是云民自己的旧航路） |
| **掘心之祸** | 星髓越采越稀，云民向礁脉最深处掘进。最深处的"心脏"——天穹之心，托举整个天海的潮枢——露出轮廓。祭殿围绕它而建，随后沦为采掘场。 | 天空神殿（由祭殿改成的矿场） |
| **裂潮之日** | 心壳被凿穿的刹那：潮水失去锚，天海三分——坠下界成熔岩，落地面成江海，余者蒸发成风。最大一块心壳卡上天穹，正午凝固。云民或坠或散。 | 永昼 / 三维度水文 / 无水体 |
| **长明之后**（现在） | 守卫仍巡逻，风灵仍游弋，残页与石碑散落群岛。直到荧石门再次亮起——玩家到来。 | 全部既有内容 + 本计划新内容 |

### 2.4 玩家旅程（五幕）

1. **第一幕·搁浅之潮**：入域求生 → 出生岛引路碑（必生成）读到最后一位守塔人的留言 → 找到瞭望塔，登顶点亮熄了万年的灯（点荧石即触发一段碑文）。
2. **第二幕·星髓与盗掘者**：发现沉船残页 → 读懂"船曾经在水上" → 在水晶秘境挖到星髓矿石 → 第一次被潮鸣袭击（偷窃者的第一课）→ 找到天空神殿。
3. **第三幕·守誓者**：神殿内殿祭坛尘封。集齐材料合成**风暴图腾**，献于祭坛 → 守誓巨像苏醒（Boss 战）→ 胜利掉落**风暴之核**与**心核碎片**。
4. **第四幕·御风者**：用战利品合成**缚风之剑 / 御风斗篷 / 风阵块** → 借上升气流与云绒块在群岛间架桥筑城，成为新的"织风者"。
5. **第五幕·复潮**（可选终局）：集齐三张潮汐残页（涨潮/星髓/裂潮）+ 心核碎片，于祭坛行**复潮仪式** → 恒昼第一次破碎，暮色与黑夜回归天域，风灵得到安息（表现层），群岛间风潮带增强。夜幕同时带来新的威胁——世界不再停在正午，也就不再是安全的了。

> 设计要点：第 1-4 幕是纯增益内容，不破坏任何既有不变量；第 5 幕动"永昼"这一维度级设定，单列为最终批次，带完整不变量清单与可回退方案（见 §5.4）。

### 2.5 叙事载体（无对话系统的环境叙事）

- **风纹石碑**（新方块）：右键打开碑文浮层（BeaconScreen 同款自包含 UI 惯例），逐章展示裂潮史。全图共 9 章，散布于出生岛/塔/船/神殿/门遗迹。
- **潮汐残页**（3 种物品）：tooltip 附多行残文（tooltip 由单行 `textContent` 扩展为支持 `lore` 行——小改动，见批次 A）。残页同时是第五幕仪式材料，"收集欲"与"叙事"合流。
- **Boss 登场**：巨像苏醒时全屏文案 + BossBar（多实例系统已有）。
- **仪式演出**：复潮完成时粒子潮涌 + 天色渐变 + 屏幕文案，不做 cutscene 脚本。

### 3.6 核心新机制：上升气流

- 判定：`Game._updateUpdraftState()` 仿 `_updateWaterState`——足部/身体所在格 `def.updraft === true`（`wind_current`）→ 每帧 `vy += LIFT·dt`，`vy` 钳上限 ~6；按住 Shift 主动下潜脱出。
- 生成端：漩风井（天然）+ 风阵块（合成，上方 12 格充能风流柱——放置时直接写方块，不搞每帧方块扫描）。
- 边界：**只作用于玩家**（怪物运动不接气流，避免 AI 被抬飞出控）；风流柱随区块生成，走 setBlock 之外的生成写入（同树冠路径，不进账本）。
- 联机：纯客户端物理，零协议改动；两端各自享受气流，位置由既有 player_state 同步。
- 性能：一次 `getBlock` 查表，无可测开销。

## 5. 技术要点与防回退

### 5.1 确定性（联机根基）
- 生成器新增装饰全部 hash3 per-column 门控；结构 solve 纯函数 of (rng, 锚点)；禁止 Math.random 进入任何生成路径。
- `dimension-determinism.mjs` 必须保持全绿（biomeNames 不变，群系集合不动；新增方块只影响装饰层，双次一致性断言天然覆盖）。

### 5.2 性能预算
- 装饰仍走 decorateChunk 尾部，预算 0.1ms/块不变；新结构复用 StructureManager cell 网格（cell/attempts/salt 三参数调节密度，salt 与既有类型错开）。
- 巨像模型走 cuboid 拼装管线（MobTextures 惯例），不引入新 mesh 类型；风弹复用弹射物实体池。

### 5.3 SVG / 注册管线
- 多面方块显式 `textures{top/side/bottom}`，同一方块只注册一次（ piston 教训）；SVG 名遵循 `<block>_top/_side/_bottom` 约定；全部带中文 displayName。
- 新增生物三件套：MobTypes 注册 + WISP/AETHER_GUARD_PARTS 同款 PARTS + MobManager 生成表。

### 5.4 永昼不变量清单（批次 D 执行，逐项打勾）
1. `skyLightLevel: 1.0` 覆盖移除 → 体素光跟随真实昼夜（uDayLight 动态）。
2. `fixedColor` 置 null → skyColors 昼夜锚点生效（0.25/0.5/0.75/1 锚点勿动）。
3. `polarDay` 关闭 → Sky.time 恢复主世界语义（存档时间字段首次对天域有意义，SaveSystem 兼容默认值 0.35）。
4. `pickAetherSpawnV2` 增加 isNight 分支（夜表：岚隼↑ 守卫↑，云绒兽夜间缩群）。
5. InfoBar 时间行：天域从"永昼"变为正常时刻显示（读档案，无硬编码分支）。
6. 云/雾/天体：celestials 保持 true，日月升起与主世界同路径。
7. 回退方案：`aetherDusk` 做成 dimDef 覆盖档案，出问题可整体一键回滚永昼（覆盖不生效 = 回到永昼行为）。

### 5.5 联机一致性
- 结构/箱表：两端确定性一致（既有纪律）。
- Boss：host 权威（龙模式）；风弹：本地结算+广播视觉（凋灵模式）。
- 仪式状态：方块置换承载（零新增持久化）；维度昼夜状态：新增 `dimension_state` 消息 + store 快照字段。
- 房间开关：Boss 召唤与风阵块交互均过既有闸门漏斗。

### 5.6 明确不做（Out of scope）
- 不做对话/NPC 任务系统；不做天域村庄；不做云鲸（远期备选）；不改 4 群系边界与岛场参数（群系名表、InfoBar 格式零改动）；不动荧石门坐标换算与到达平台语义；主世界/下界/末地零改动（三维度水文呼应只存在于文案，不实装联动机制）。
