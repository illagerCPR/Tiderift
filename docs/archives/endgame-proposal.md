## 1. 终局要回答的最后一个问题

世界观的四界都已落地，只剩一个谁也没有回答过的问题：

> **潮从哪里来，回哪里去？**

- 雨民不知道（祖训只记得"最早的年头，雨是咸的"）；
- 火民不问（炉还烧着）；
- 云民不敢问（掘心之祸是他们凿出来的）；
- 拾遗者的王在等——**等什么，碑文不写满**。

而总纲 §2.1 早已埋好答案的名字：**原初之潮**——世界诞生时那一片包裹所有界层的海。裂潮之日，海一分而三（坠火 / 落雨 / 散风），唯独末地不及。天域复潮（Build 14）把**心**送回了位（心核归位），但碑文写得清楚："潮水不再，潮信长存"——心跳回来了，**血还没有**。

终局「潮归其位」就是补上这最后一下：让世界的这颗心，**完整地跳一次**。

---

## 2. 「原初」的三重含义（设想的骨架）

### 2.1 时间上的原初——让原初之潮"再涨一次"

原初之潮不是水，是**世界的脉搏**。总纲的缝合链已经给了全部零件：星髓是潮的骨头（天域 §2.3），心壳是潮的心（天穹之心），三潮是血在三个心腔里的残样。复潮归位的是心核，终局要做的是让脉搏搏动一次——**四界同时涨落一次**，然后永远退去。潮水不复存在，但四界都听过了那声心跳。

### 2.2 空间上的原初——无潮彼岸是原初的底片

末地"保留着涨潮之前的世界底色"（§3.4）。它是唯一没被潮**写过**的一页——所以它是唯一能**读出原初**的地方。终局仪式的最后一环必须在末地完成，但方向不是"把潮带到末地"，而是**在末地听潮**：无潮之岸是这颗心的听诊器。这同时保住两条底线——末地永不被水覆盖（§3.4 设定不动）、留白不写满（王在等什么，碑文依旧不说）。

### 2.3 机制上的原初——仪式的完成态

- **三证 = 三个心腔的旧血样**（风潮 / 坠潮 / 雨潮）；
- **潮心祭坛 = 心位**（复潮后的既有方块，天域终局的产物）；
- **末地主岛守望界碑 = 听潮位**（E2 刚落地的界碑，断句处就是为今天留的）。

三者在空间上分处四界中的三界与彼岸——收集线本身就是"走完四界碎片"（§6.4 红线原文），终局不新增任何一条刷取链，**只收割既有旅程**。

## 4. 第四证的两种处理（评审点 2）

末地是"无潮"——它拿不出潮的遗物。两种方案：

- **方案一「到场即证」（推荐主体）**：无第四证。三证提交于潮心祭坛后获得"候潮"状态，玩家必须**携带纹章胚（或三证）亲自站到主岛守望界碑前**完成听潮环节。末地的证 = 玩家的到场——与 §6.4"收集线本身就是走完四界碎片"完全同构，零新物品。
- **方案二「王所守之物」（可选点缀，可与方案一叠加）**：龙蛋补一段 lore 重释（"王从滩涂尽头衔来的、涨潮之前的东西"），仪式时若背包有龙蛋可一并放入——**不解释王在等什么**，只给王一个低头的动作（见 §6 终章文案）。零机制改动，仅 lore 与演出。

## 5. 机制形态三案（评审点 1）

> 共同前提：门槛 = 复潮已完成（潮心祭坛在场）+ 三证齐。三案都**零地形改动、零群系改动、零新刷取链**；差异在演出范围与交付物数量。

### 方案 A 全形态「四界同潮」——预估 2-3 批次

1. **候潮**：潮心祭坛提交三证 → 祭坛进入候潮态（复用复潮的"方块置换"模式，新增 1 个方块 id `primordial_altar` 原初祭坛，append-only）；
2. **听潮**：末地主岛守望界碑右键（候潮状态门控）→ **原初之潮事件**，四界各一段纯演出（≤60s，粒子 + 天空/雾色临时覆盖，结束全还原）：
   - 天域：风涨一次——粒子潮涌沿岛列起伏，天空短暂回到潮平纪元色（复用 skyColors 锚点）；
   - 下界：熔岩海潮涌演出（雾色 + 粒子，不动流体）；
   - 主世界：一场不落地的逆雨（自海面升回天顶的粒子）；
   - 末地：**潮声过岸**——一圈潮线粒子掠过滩涂边缘，不沾一岸。
3. **交付物**：新物品 **原初纹章 `primordial_emblem`**（仪式完成发放/合成，纯展示）+ 终章文本（承载方式见评审点 3）。

工程量：新方块 1 + 新物品 1 + 四界演出管线（复用复潮粒子/天空基建）+ i18n ≈ 15-25 键 ×10 包 + 联机状态位 1 个 + 测试 1 套。

### 方案 B 中间形态「一岸听潮」——预估 1-2 批次（推荐）

只做末地一侧的仪式：候潮（祭坛提交三证，**不换方块**，用状态位）→ 主岛界碑右键 → 单界演出（潮声 + 潮线掠岸 + 天空色）+ 原初纹章 + 终章。其余三界的"潮归"全部由纹章 lore 一笔带过（"风息了，炉暖了，雨停了"）。演出管线只建一套（末地），是方案 A 的一半成本，但叙事密度最高——**终局发生在潮的出生地**。

工程量：新物品 1 + 单界演出 + 状态位 + i18n ≈ 10-15 键 ×10 包 + 测试。

### 方案 C 降级形态「原初纹章」——1 批次内（§6.4 红线预案）

无仪式无演出：三证在合成台合成 **原初纹章**（图形合成，确定性），lore 3 行写完终章。零演出、零状态位、零联机影响。这就是 §6.4 原文的降级方案，只是把名字从"三潮纹章"定为"原初纹章"。

### 共同不变量清单（预登记，立项时逐项复核）

1. **无潮彼岸永不被水/流体覆盖**——一切演出走粒子与天空/雾色临时覆盖，`end.js` 地形与群系函数零改动；
2. 复潮档案（`aetherDusk` 三路持久化）语义不动；终局状态位用**新增独立字段**（如 `data.finaleDone`），不改旧字段；
3. 龙战 / 出口传送门 / 折跃门配对 / 龙蛋掉落链不动（龙蛋重释仅 lore）；
4. 三证掉落参数零回调；
5. 演出为客户端本地表现，**不进存档不进联机账本**（体素光照同款边界）；状态位走存档 + 联机 profile（数值强校验先例）；
6. append-only：潮心祭坛既有右键行为（renewal 章）不动，终局交互挂在**守望界碑**上，不叠旧交互；
7. 每维碑文章节数克制（§8）：终章优先走纹章 lore 而非新增碑文章节。

## 6. 文案示意（让设想可感，均可再改）

**原初纹章 lore（3 行，三案通用）**：

> 「风潮、坠潮、雨潮——三枚旧心跳在掌心合成了一声。」
> 「无潮的岸边，你听见了它：海还没有名字的时候，原初之潮就是这样响的。」
> 「潮不会回来。但世界记起了自己曾经是一整片海。」

**守望界碑终章「原初」（若走碑文承载，3 行）**：

> 「凿碑的人回来了。他没有把断句刻满，只是在碑座上放了一枚纹章。」
> 「王没有动。潮声过岸的那一刻，它把头低了下去——第一次，也是最后一次。」
> 「碑文到这里真正结束了。剩下的字，原初自己会读。」

> 留白纪律核对：王在等什么**仍然没有答案**——文案只给了王一个低头的动作，不解释等待的内容。"原初自己会读"把最后一行字永远留给世界本身。与 E1 守望章"剩下的字，要等王自己来刻"闭环：王没有刻——它只是低下了头。

**复潮章呼应**：renewal 章"愿你的船，比我们的走得更远"——船最终驶到的，是潮的出生地。

## 8. 评审结论（2026-09-15 已拍板）

1. **形态：方案 A 四界同潮**（已选定；"同时"的技术含义 = 全局时间窗 60s，四界分段并行，玩家换维即见彼界段落——单机可追潮跑四界，联机全员各见本界段）；
2. **第四证：到场即证为主 + 龙蛋 lore 点缀可叠加**（王在等什么保持留白，只给低头的动作）；
3. **终章承载：纹章 lore**（碑文留白纪律最干净，无可达性门控问题）；
4. **联机：host 权威**（状态位走 profile/room flag，演出为各端本地表现）；
5. **排期：拍板即立项预备**——开发计划见 §10，**待确认后按 §9 模板开工**。

### 10.3 成本与风险

- i18n 总量 ≈ 10（F1）+ 8（F2 提示）+ 6（F3 系统消息）≈ **24 键 ×10 包**；names.js 新增 2 行（原初祭坛/原初纹章）。
- 新 id 仅 2 个（方块 1 + 物品 1），append-only；零地形/群系/流体/掉落/龙战改动——全部演出走粒子与天空/雾临时覆盖。
- 风险①：四界演出管线体量最大——F2 若超预算，可拆为 F2a（调度器+末地/天域段）/ F2b（下界/主世界段），批次表顺延但 F3 内容不变；
- 风险②：换维追潮的时间窗体验——60s 是否够跑传送门，冒烟阶段实测可调（只改常量）；
- 风险③：LAN 时钟偏移——startTs 用 host 时间戳 + 客户端偏移对齐（阶段 5 插值同款先例），冒烟验证；
- 回退预案：F3 若延期，F1+F2 已是自洽的"候潮+四界演出"增量（纹章延后发放），不影响既有版本。
